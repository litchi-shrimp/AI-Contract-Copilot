# version-control 技能

## 功能说明
- **回退到指定版本**：支持回退到最近版本或指定时间戳的版本
- **列出备份版本**：显示所有可用的备份版本及其描述

## 工具列表

### 1. rollback
**功能**：回退到指定版本的大纲

**参数**：
- `version` (string)：版本标识，可选值：'latest'（最近版本）或具体的时间戳
- `reason` (string)：回退原因

**返回值**：
- 回退结果，包含成功或失败信息

### 2. list_backups
**功能**：列出所有可用的备份版本

**参数**：
- 无

**返回值**：
- 备份版本列表，包含时间戳和描述信息

## 使用场景
1. **用户改变主意**：当用户在修改后反悔，想要恢复到之前的版本
2. **错误修改**：当修改操作导致了错误，需要回退到正确的版本
3. **版本管理**：当需要查看所有可用的备份版本，以便选择合适的版本回退

## 工作原理
1. **备份创建**：每次修改操作前，系统会自动创建大纲的备份
2. **版本识别**：通过时间戳唯一标识每个备份版本
3. **回退机制**：根据用户指定的版本标识，从备份中恢复大纲
4. **备份管理**：系统会自动清理旧备份，最多保留10个备份版本

## 示例

### 回退到最近版本
```
user: 我不想添加刚才的条款了
agent: ✅ 已成功回退到版本 latest。原因：用户请求回退: 我不想添加刚才的条款了
```

### 列出备份版本
```
user: 查看所有备份版本
agent: 可用备份版本：
1. 20231201_123456 - 修改前备份 - insert_clause
2. 20231201_123000 - 修改前备份 - update_clause
3. 20231201_122500 - 初始备份
```

## 注意事项
- 备份文件存储在 `{outline_path}/backups/` 目录中
- 每次修改操作都会创建新的备份
- 系统最多保留10个最新的备份版本
- 回退操作会覆盖当前大纲，操作前请确认
